TOWARDS MODEL-DRIVEN SYSTEMS

xFrame · Exergy ∞ LLC

Applied the same model-driven principles used in infrastructure engineering to AI-assisted content and knowledge workflows.

xFrame explores how domain models can become the foundation for reliable, reproducible communication systems — transforming structured source into documents, dashboards, presentations, and multimedia outputs through deterministic build pipelines.

  • Author once in a declarative format; compile through an intermediate representation into multiple delivery targets
  • Make provenance and reproducibility first-class so outputs can be reviewed, regenerated, and evolved as the underlying model changes
  • Constrain AI-assisted generation through schemas, templates, and explicit transformation stages rather than prompt-to-output workflows
  • Extend the operational model-driven approach from network infrastructure into AI-enabled systems

Open source · xYang

Practical YANG subset for runtime semantic validation, cross-references, and structural rules — foundational to model-driven correctness.

Across my career I am an inventor on 33 U.S. patents; SIP message prioritization from this Bell Labs work is one of them. That is where my control-plane engineering started.

In February 2024, I co-presented Compute Differently with Dan Desjardins at Civo Navigate in Austin. The idea was to rethink sustainable value creation. We demonstrated the concept live by creating an ad-hoc compute cloud from devices in the audience, then scaled the same pattern to a larger astrophysics workload across partner compute groups. For me, this brought together distributed systems, network architecture, sustainable computing, and a broader question: how can technology create more value from the resources we already have?
